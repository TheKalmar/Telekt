# Changelog

Telekt follows [Keep a Changelog](https://keepachangelog.com/en/1.1.0/) and will
use semantic versioning after the first public release.

## [Unreleased]

### Added

- Portfolio-grade CI for Python 3.11 and 3.12.
- Automated lint, formatting, coverage, behavior-fixture, security, dependency,
  and Docker Compose validation.
- Pull-request and issue templates plus engineering-quality guidance.
- Browser security headers, request correlation IDs, and regression tests for
  model, runtime, and provider URL boundaries.

### Changed

- Public package metadata now identifies the project as Telekt.
- English is the source and first-run interface language; Serbian remains an
  explicitly selected localization.
- API request contracts reject unsupported enum values before execution.

## [0.1.0] - Unreleased

Initial proof of concept for durable, governed multi-agent digital companies.
